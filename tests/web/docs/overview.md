# web-tests

The auth app's tests (the OAuth providers, the generated secret, the health route and the sign-in redirects, over real SQLite with the migrations applied), run on every pull request

The test suite for **web**. It deploys nothing: its lane installs, builds and runs the tests.

|              |                      |
| ------------ | -------------------- |
| Type         | `turbo-package`      |
| Source       | `tests/web`          |
| Package      | `@app/web-tests`     |
| Environments | `dev`: `quick-check` |
