# better-auth-starter

zpg6's [better-auth-cloudflare OpenNext example](https://github.com/zpg6/better-auth-cloudflare/tree/main/examples/opennextjs)
— open-source authentication with [better-auth](https://www.better-auth.com):
anonymous, email and OAuth sign-in, sessions in Workers KV, users in a
Cloudflare D1 database and file uploads in R2 — on **Cloudflare Workers +
Static Assets** through [`@opennextjs/cloudflare`](https://opennext.js.org/cloudflare),
its three bindings provisioned by Terraform through
[Orun](https://github.com/sourceplane/orun), and packaged as an **Orun
baseline**.

Being built: see [`specs/epics/better-auth-starter`](specs/epics/better-auth-starter/README.md)
for the design and the milestones. The example and the wrapper are MIT
